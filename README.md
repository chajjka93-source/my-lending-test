# Марина Чайка — ИИ-помощники для малого бизнеса

Репозиторий: https://github.com/chajjka93-source/my-lending-test

Сайт на Vercel: https://my-lending-test-theta.vercel.app/ (ссылка из карточки GitHub; развёртывание текущего редизайна нужно проверять отдельно).

Сайт-портфолио Марины Чайки на HTML, CSS и JavaScript: услуги, цены и проекты. Основное предложение — ИИ-помощники для малого бизнеса. Самих ботов, нейросетей, сервера, базы данных и платежей в этом репозитории нет. Переписка на первом экране — демонстрация, не живой чат.

## Что нужно для работы

- Для просмотра — браузер и файлы проекта.
- Для проверки кода — Node.js; в рабочей среде использовалась версия 24.
- Для локального HTTP-сервера — Python 3, если выбираете этот способ запуска.
- Для получения и отправки кода — Git и доступ к GitHub.

Установка npm-пакетов не нужна: package.json, сборщика и внешних JavaScript-библиотек нет. API-ключи и .env не нужны: код не читает переменные окружения. Интернет нужен для Google Fonts и переходов во внешние сервисы; без веб-шрифтов используются системные sans-serif.

## Что работает

Карточка Direct Reports в разделе кейсов содержит ссылку на внешнее [демо приложения](https://direct-reports.vercel.app/demo). Исходники этого приложения не входят в репозиторий лендинга.

Светлая и тёмная темы, мобильное меню, FAQ, квиз из трёх шагов, проверка контактной формы, подготовка и копирование текста, ссылки на мессенджеры и email. Предусмотрены видимый клавиатурный фокус и уменьшенная анимация.

По умолчанию главная страница открывается в светлой теме. Кнопка ◐ переключает светлую и тёмную темы на текущей странице. Формы не отправляют заявки: посетитель сам вставляет и отправляет текст в Telegram. Если копирование недоступно, сайт предлагает скопировать выделенный текст вручную. Код не сохраняет выбранную тему и ответы в localStorage, sessionStorage или cookies.

Квиз спрашивает сферу бизнеса, цель и детали задачи; имя и описание нужны для подготовки запроса, ссылка на сайт или соцсети необязательна. Контактная форма проверяет имя, email и сообщение, затем показывает готовый текст. Можно вернуться к ответам квиза или контактной форме для редактирования.

Спецификация в thoughts/shared/specs описывает будущий бот, панель мастеров, записи, напоминания и подписку. Их серверной реализации здесь нет. Подробности — в [ARCHITECTURE.md](ARCHITECTURE.md#спецификация-и-реализация).

## Как проверить

Из папки проекта:

```powershell
node verify.cjs
git diff --check
```

`verify.cjs` проверяет синтаксис встроенного JavaScript, дубли ID, якоря и наличие `premium.css`. Это не проверка изображений, доступности или работы интерфейса. Отсутствие CSS выводится как `css: false`, но само по себе не устанавливает ненулевой код завершения. `git diff --check` проверяет ошибки пробелов в diff.

Для браузерной проверки нужен отдельно запущенный Chromium-браузер с CDP на `127.0.0.1:9333`, отдельным профилем и хотя бы одной вкладкой, а также Node.js с встроенными `fetch` и `WebSocket` (здесь использовался Node.js 24):

```powershell
node browser-review.cjs
```

В текущем скрипте URL жёстко задан: `file:///C:/Users/Марина/Documents/Projects/my-lending-test/index.html`. На другом компьютере его нужно изменить. Скрипт сохраняет скриншоты на ширинах 1440 и 390 px, выводит ширину страницы и проверяет открытие меню, Escape, FAQ, подготовку сообщения контактной формы и возврат к форме. Он не переключает темы и не проверяет квиз, ошибки полей, копирование, Tab, изображения или ошибки браузерной консоли. Оценивайте значения в выводе: `false` в результатах взаимодействий не приводит к ненулевому коду завершения. Уточнение пути здесь соответствует коду; описание относительного пути в `docs/TECHNICAL.md` устарело.

Перед завершением правок проверьте обе темы, меню и Escape, квиз, ошибки формы, копирование, FAQ и телефонную версию.

11 октября 2026 года локально выполнены `verify.cjs`, `git diff --check` и `browser-review.cjs`. Дополнительная проверка через CDP охватила обе темы на 1440 и 390 px: переключение тем, прохождение и редактирование квиза, его ошибку при отсутствии выбора, ручной режим копирования и видимый фокус после Tab. Горизонтального переполнения и исключений JavaScript в этой дополнительной проверке не обнаружено; после принудительной загрузки отложенных изображений все изображения загрузились. Автоматическая запись в буфер обмена и опубликованная версия сайта не подтверждены. Скриншоты первых экранов сохранены в `review-output/`.

Тексты, цены, контакты и ссылки меняются в index.html. Текущий дизайн — в premium.css, подключённом после встроенных стилей. Секреты в HTML и CSS не добавляйте.

В репозитории нет vercel.json и настроек автоматического развёртывания. Успешный push в GitHub не подтверждает публикацию Vercel. .openai/hosting.json содержит идентификатор проекта Sites, не настройки базы или API.

# Марина Чайка — ИИ-помощники для малого бизнеса

Репозиторий: https://github.com/chajjka93-source/my-lending-test

Сайт на Vercel: https://my-lending-test-theta.vercel.app/ (ссылка из карточки GitHub; развёртывание текущего редизайна нужно проверять отдельно).

Статический сайт на HTML, CSS и JavaScript без сборщика и собственного API. Основное предложение — ИИ-помощники для малого бизнеса. Реальные кейсы, цены и контакты сохранены.

## Где искать и как открыть

Рабочая копия GitHub на компьютере: `C:\Users\Марина\Documents\Projects\yandex-direct-lending\github-sync`.

В Проводнике откройте эту папку и дважды нажмите `index.html`: сайт откроется в браузере. Для редактирования откройте папку `github-sync` в VS Code.

| Файл | Назначение |
| --- | --- |
| `index.html` | Страница, базовые стили и сценарии интерфейса |
| `premium.css` | Палитра, типографика, темы, адаптация и фокус |
| `privacy.html` | Политика конфиденциальности |
| `assets/` | Фото автора и реальные скриншоты проектов |
| `docs/AI-DESIGN.md` | Дизайн-система и проверки доступности |
| `docs/TECHNICAL.md` | Устройство проекта и работа с Git |
| `preview-desktop.png`, `preview-mobile.png` | Превью редизайна с системными шрифтами |

Дизайн: светлая бирюзовая палитра, Golos Text для заголовков и Source Sans 3 для текста. Предусмотрены тёмная тема и видимый клавиатурный фокус.

Проверка кода из папки проекта: `node verify.cjs`. Формы готовят сообщение в браузере; посетитель самостоятельно отправляет его в Telegram.

Параллельная копия для ChatGPT Sites находится в `../studio-source`, где исходники лежат в `public/`, а публикуемая копия — в `dist/`. Не путайте её с этой структурой GitHub: здесь файлы сайта находятся в корне.

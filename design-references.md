## Принятое направление

Молочный фон, графитовый текст, оливковый акцент. Крупная типографика Manrope, тонкие разделители, больше свободного пространства, плоские кнопки и блоки. Первый экран связывает личный бренд Марины Чайки с тремя направлениями работы. Геометрическая графика выполнена в SVG и CSS без внешних изображений.

Сохранены цены, сроки, статусы проектов и контакты. Схематичный интерфейс незавершённого проекта явно подписан как концепция. Форма сохраняет исходный сценарий подготовки сообщения в браузере; пользователь отправляет его самостоятельно. Для меню добавлены Escape, inert и aria-controls; для FAQ — aria-expanded.

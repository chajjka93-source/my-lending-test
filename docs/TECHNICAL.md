## Интерфейс и данные

Разделы: предложение ИИ-помощника, пример ответа с источником, квиз для разбора задачи, автор, услуги, реальные проекты, процесс, цены, контактная форма и FAQ.

Две темы, семантические цветовые токены, видимый фокус 3px, ссылка пропуска навигации, Escape для меню, aria-describedby для ошибок, скрытие закрытых блоков от клавиатуры. Дизайн-система — в [AI-DESIGN.md](AI-DESIGN.md).
